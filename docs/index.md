## 🛠 Core Modules

* **[📅 Car Booking & Reservations](./carbooking.md)**
  Explore our high-performance car discovery engine. It features Prisma-based server-side filtering for location and date, backed by real-time availability logic to prevent double-bookings.

* **[💳 Payment & Invoicing](./payment.md)**
  A secure transaction workflow integrated with **Stripe**. Once a booking is confirmed, users can manage their payment history and generate on-demand, client-side PDF invoices using `jsPDF` and `html2canvas`.

* **[🧪 Quality Assurance & Testing](./testing.md)**
  Maintaining a robust codebase through **Vitest** and **React Testing Library**. This includes unit tests for tRPC procedures and integration tests for complex UI interactions like portal-based dialogs and document generation.
